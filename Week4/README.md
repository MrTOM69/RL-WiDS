# Week 4 – RL Trading Project

This week implements the core Reinforcement Learning framework for a stock trading task.  
A custom trading environment is created and a tabular Q-learning agent is trained to perform Buy, Sell, and Hold actions using historical price data.  
The agent is evaluated on unseen data and compared with a Buy-and-Hold baseline strategy.  
This notebook forms the foundation for further extensions such as Deep RL and technical indicators.
This is the last assignment in this project. Hope you enjoyed learning RL and its applications in trading!
